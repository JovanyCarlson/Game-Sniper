Private GameSniper

Your monitoring history is encrypted with AES-256-GCM. Enter your secret key to unlock it. The key stays in this browser tab and is never sent to GitHub or our server.

For first-time setup, generate and copy the new key into GitHub → Settings → Secrets and variables → Actions → GAMESNIPER_STATE_KEY. Keep a private copy: lost keys cannot decrypt previous history.

Only sample data is available publicly at preview mode. All real observations are encrypted.
